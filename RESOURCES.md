# Recommended Resources

Dictionaries, frequency lists, pitch accent data and word audio for each mining language.

- **Setup Wizard: Yes** marks the set that Tools -> Setup Wizard and Tools -> Download Recommended Resources install for the active mining language. Add the others by hand.
- **Add via** is a path under Settings. Add a resource while its language is the mining language (Settings -> Mining Language): it is filed under the language active when you add it.
- Keep a Yomitan ZIP intact when adding it (do not unzip it).
