## Regenerating the rule table against a newer upstream

`japanese_transforms.py` is generated by materializing the upstream ES module
(generator helpers pre-expanded), not hand-transcribed:

1. Clone yomitan at the desired commit.
2. With node, `import {japaneseTransforms}` from
   `ext/js/language/ja/japanese-transforms.js` and dump each transform's
   `rules` (for suffix rules: regex source minus the `$` anchor +
   `deinflected`; for whole-word rules: regex source minus `^`/`$` +
   `deinflect('')`), plus the `conditions` tree, to JSON.
3. Emit the Python module from that JSON (one
   `suffix_inflection`/`whole_word_inflection` call per rule, upstream
   argument order), update the pinned commit hash in the file header and in
   `tests/unit/test_deinflection.py` (materialized rule counts), and run the
   differential check: the Python `Deinflector.transform` result set must be
   identical to upstream `LanguageTransformer.transform` on the test corpus.
