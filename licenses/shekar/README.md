# shekar

`anki_miner/languages/fa/data/colloquial.tsv` carries 108 informal→formal Persian
word pairs taken from shekar 1.6.3's `informal_words.csv`
(https://github.com/amirivojdan/shekar), MIT licensed, © 2024 Ahmad Amirivojdan
— the text beside this file. The `source` column of every such row reads
`shekar`.

Nothing else from shekar ships: no code is ported or imported, and its ONNX
part-of-speech tagger is not used.
