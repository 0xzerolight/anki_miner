en_core_web_sm - spaCy English pipeline (MIT)
Release: https://github.com/explosion/spacy-models/releases/tag/en_core_web_sm-3.8.0
Model source and training configuration: https://github.com/explosion/spacy-models

Training data, as listed in the model's own meta.json:
  OntoNotes 5 (commercial, licensed by Explosion) - https://catalog.ldc.upenn.edu/LDC2013T19
  ClearNLP Constituent-to-Dependency Conversion (citation only, no code packaged) - https://github.com/clir/clearnlp-guidelines
  WordNet 3.0 (WordNet 3.0 License) - https://wordnet.princeton.edu/
The full texts of those terms are the wheel's own LICENSES_SOURCES file, which
stays beside the model data after the language pack is extracted
(~/.anki_miner/language_packs/en/en_core_web_sm/en_core_web_sm-3.8.0/LICENSES_SOURCES).

The binary this application downloads is the unmodified wheel
en_core_web_sm-3.8.0-py3-none-any.whl. Its URL and SHA-256 digest are pinned in
anki_miner/languages/en/pack.py; corresponding source for that exact version is
available from the release and repository URLs above.
